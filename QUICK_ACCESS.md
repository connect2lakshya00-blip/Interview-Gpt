## 🐛 Quick Fixes

### Not Logged In
→ Go to /login

### Microphone Not Working
→ Click 🔒 → Allow Mic → Refresh

### Upload Failed
→ Check file size < 5MB
→ Check file type (PDF/DOCX)

### Servers Not Running
```bash
cd backend && npm run dev
cd frontend && npm run dev
```
