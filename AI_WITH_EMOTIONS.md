## 🚀 How to Use

### Start Your Servers:

**Backend:**
```bash
cd backend
npm run dev
```

**Frontend:**
```bash
cd frontend
npm run dev
```

### Test the Features:

1. **Go to AI Assistant**: http://localhost:3000/dashboard/ai-assistant

2. **Test Emotional Responses:**
   - "I'm frustrated with this code" → Get empathy
   - "I'm so excited I solved it!" → AI celebrates with you
   - "I'm confused about X" → Patient explanation
   - "I'm feeling down" → Supportive response

3. **Test PDF Upload:**
   - Click 📎 paperclip button
   - Select a PDF file
   - Wait for success message
   - Ask: "Summarize this document"
   - Ask: "What are the key points?"
